# Meditations

Sample skill folder. Public-domain illustration of the format Bindlore emits (`SKILL.md` plus chapter references). This was not produced by scanning or OCR, and it is not taken from a copyrighted modern edition.

## When to use this skill

Use it when the user asks about *Meditations*, Marcus Aurelius, or a Stoic passage that might be in the reference files. Read the matching file under `references/` and quote from it.

## Citation style

Name the work, book, and section, and point at the reference file:

> Meditations, Book II, §I (`references/book-02.md`)

Do not invent quotations. If a passage is not in `references/`, say it is not in this sample.
