# Bindlore marketing site

Static marketing site for **Bindlore** — turn books you own into on-device AI skills.

## Domain

Production domain: `bindlore.app` (already purchased on Vercel).

## Deploy

1. Import `stedeim/bindlore-web` into Vercel (framework: Other / static).
2. Attach custom domain `bindlore.app`.
3. Confirm `/privacy/` and `/demo/bindlore-demo-16x9.mp4` resolve.

## Notes

- Chrome Web Store is not live yet — site CTAs say **Coming soon**.
- Demo video lives at `demo/bindlore-demo-16x9.mp4`.
- Do not mix with SubQuotes assets or lists.
