Bindlore exports right-to-use books as SKILL.md reference packages for Claude, Codex, and custom agents

Calgary, Alberta — September 17, 2026

Bindlore, a free Chrome extension by Deimira Baidoo, targets a narrow job: turn a DRM-free book or document the user has the right to process into an agent-readable reference package — not a raw text dump. The export is an AI Skill package — SKILL.md plus chapter and section reference files — structured so Claude, Codex, Claude Code workflows, and other Markdown-reading agents can search and quote material the user provided. Conversion structures source material for compatible agents; it does not guarantee agent quality, accuracy, or performance.

Parsing and skill-building run in the browser. There is no Bindlore cloud for book content on the core path. Users can also export Markdown, Word, or plain text when they do not need a full skill folder. Optional AI extras use the user’s own OpenAI or Anthropic API key, with requests sent directly from the browser to the provider.

Deimira Baidoo framed the product around tools he already uses. “The problem isn’t buying books — it’s finding the useful part when I need it, and getting that into the tools I work with every day,” he said. Batch convert is supported so a shelf of DRM-free files can become one skill bundle instead of one-off cleanups. DRM-locked files are refused on purpose.

Product facts

  • Primary export: AI Skill (SKILL.md + chapter references)
  • Also exports: Markdown, Word, Text
  • Built for Claude, Codex, and agents that read Markdown
  • Inputs: PDF, EPUB, Word, PowerPoint, TXT, photos/scans (on-device OCR)
  • Core path: on-device; no account required
  • DRM-locked files refused on purpose
  • Conversion does not guarantee agent quality
  • Optional AI extras: user API key; browser → provider
