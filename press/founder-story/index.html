Calgary builder Deimira Baidoo ships Bindlore: right-to-use books to on-device skill files

Calgary, Alberta — September 17, 2026

Deimira Baidoo (he/him), a Calgary-based builder and developer, has launched Bindlore, a free Chrome extension that converts books and documents users have the right to process into on-device skill files for Claude, Codex, and custom agents.

The product came from a concrete gap. He wanted a Chrome extension that could turn a personal library into agent-readable SKILL.md packages without uploading paid books to someone else’s cloud. He did not find one that fit his local-processing requirement, so he built Bindlore. Parsing, OCR, and skill-building run in the browser. There is no Bindlore cloud for book content on the core path. DRM-locked files are refused on purpose. Conversion structures source material for compatible agents; it does not guarantee agent quality, accuracy, or performance.

“I own a lot of books. The problem isn’t buying them — it’s finding the useful part when I need it, and getting that into the tools I work with every day,” he said. “I wanted conversion that stays on my machine — handing paid books to a vendor cloud wasn’t acceptable.”

The core convert path is free and requires no account. Optional AI extras use the user’s own OpenAI or Anthropic key; requests go from the browser to the provider. Deimira Baidoo’s broader project work is optionally cited at https://deimira-builds.vercel.app.
