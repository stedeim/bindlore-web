Bindlore launches: free Chrome extension converts books and documents into on-device skill files for Claude and Codex

Calgary, Alberta — September 17, 2026

Bindlore, built by founder Deimira Baidoo, is available on the Chrome Web Store. The free extension converts books and documents the user has the right to use into structured skill files — a SKILL.md file plus chapter references — for Claude, Codex, and other agents that read Markdown. Parsing, OCR, and skill-building run in the browser on the user’s device. Conversion structures source material for compatible agents; it does not guarantee agent quality, accuracy, or performance.

Deimira Baidoo built Bindlore after searching for a Chrome extension that could turn a personal library into structured skill files and finding nothing that fit his local-processing requirement. “I own a lot of books. The problem isn’t buying them — it’s finding the useful part when I need it, and getting that into the tools I work with every day,” he said. “I wanted conversion that stays on my machine — handing paid books to a vendor cloud wasn’t acceptable.”

The core convert path requires no account. Bindlore does not send book content to any Bindlore server on that path. DRM-locked files are refused on purpose: the product is a converter for content the user has the right to use, not a DRM workaround.

Product facts

  • Free core convert; no account required for the core path
  • Inputs: PDF, EPUB, Word, PowerPoint, TXT, and photos/scans (on-device OCR)
  • Export: AI Skill (SKILL.md + chapter references), Markdown, Word, or plain text
  • Optional AI extras (summaries, glossary, Anki cards) use the user’s own OpenAI or Anthropic key; requests go from the browser directly to the provider — not through Bindlore
  • DRM-locked files refused on purpose
  • No Bindlore cloud for book content on the core path
  • Conversion structures source material; it does not guarantee agent quality
