Press kit

Bindlore press materials

Bindlore is a free Chrome extension. It converts books and documents the user has the right to use (and right to process) into on-device AI skills (SKILL.md) for Claude and Codex. Parsing and OCR run in the browser. There is no Bindlore cloud for book content on the core path. DRM-locked files are refused on purpose. No account is required for core convert. Ownership alone is not blanket permission.
