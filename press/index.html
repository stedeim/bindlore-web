Bindlore launches free Chrome extension that turns books you own into on-device AI skills for Claude and Codex

For immediate release · September 15, 2026 · Calgary, Alberta

Bindlore is now live on the Chrome Web Store. It converts books and documents the user already owns into structured AI skills (SKILL.md plus chapter references), with parsing, OCR, and skill-building running in the browser on the user’s device.

Add to Chrome Visit bindlore.app

Launch release

Calgary, Alberta — September 15, 2026 — Bindlore, a free Chrome extension from founder Deimira Baidoo (he/him), is live on the Chrome Web Store. Bindlore turns books and documents users already own into structured AI skills for Claude, Codex, and other agents that read Markdown.

Baidoo built Bindlore after trying to turn his own library into agent-ready skills and finding no extension that kept conversion local. Bindlore was built around a simple privacy principle: conversion for owned content should run on the user’s machine, not a vendor cloud.

“I own a lot of books. The problem isn’t buying them — it’s finding the useful part when I need it, and getting that into the tools I work with every day. A lot of converters want your pages in their cloud. That wasn’t acceptable for books I paid for.” — Deimira Baidoo

Product facts

  • Free core convert with no account required.
  • Supports PDF, EPUB, Word, PowerPoint, TXT, and photos/scans (OCR runs on-device).
  • Exports AI Skill (SKILL.md + references), Markdown, Word, or Text.
  • Optional AI extras (summaries, glossary, Anki) use the user’s own OpenAI or Anthropic key; requests go from browser to provider.
  • No Bindlore cloud for book content on the core path; parsing and skill building run in-browser on the user’s device.
  • DRM-locked files are refused on purpose — Bindlore is a converter for content users have the right to use, not a DRM workaround.
