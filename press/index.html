Bindlore launches free Chrome extension that turns books you own into on-device AI skills for Claude and Codex

Calgary, Alberta — September 15, 2026

Bindlore, a free Chrome extension from founder Deimira Baidoo, is now live on the Chrome Web Store. Bindlore converts books and documents the user already owns into structured AI skills (SKILL.md plus chapter references) for Claude, Codex, and other agents that read Markdown — with parsing, OCR, and skill-building running in the browser on the user’s device.

Baidoo built Bindlore after looking for a Chrome extension that could turn a personal library into agent-ready skills and finding nothing that fit. “I own a lot of books. The problem isn’t buying them — it’s finding the useful part when I need it, and getting that into the tools I work with every day,” he said. “A lot of converters want your pages in their cloud. That wasn’t acceptable for books I paid for.”

Product facts

  • Free core convert; no account required for the core path
  • Supported inputs include PDF, EPUB, Word, PowerPoint, TXT, and photos/scans (on-device OCR)
  • Export as AI Skill (SKILL.md + references), Markdown, Word, or Text
  • Optional AI extras (summaries, glossary, Anki) use the user’s own OpenAI or Anthropic key; requests go from browser to provider
  • DRM-locked files are refused on purpose — Bindlore is a converter for content the user has the right to use, not a DRM workaround
  • There is no Bindlore server for book content on the core path
