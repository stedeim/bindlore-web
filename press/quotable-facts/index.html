Bindlore — quotable fact sheet for journalists

Use this one-pager with any single-angle release. Do not invent metrics beyond what is listed here.

One-line

Bindlore is a free Chrome extension that converts books and documents you have the right to use into on-device skill files (SKILL.md) for Claude, Codex, and other agents that read Markdown. Conversion does not guarantee agent quality.

What / where / how

Inputs and exports

  • Inputs: PDF, EPUB, Word, PowerPoint, TXT, photos/scans (OCR on-device)
  • Exports: AI Skill (SKILL.md + references), Markdown, Word, Text
  • Batch: Drop several files; get a skill bundle

Optional AI extras

  • Features named on site: summaries, glossary, Anki cards (also described as insights in homepage marketing copy)
  • Uses the user’s own OpenAI or Anthropic API key
  • Requests travel browser → provider — not through a Bindlore book-content cloud
  • Not required for core convert

Explicit non-claims (do not print as Bindlore claims)

  • No verified user counts, revenue, awards, or partnership logos in this pack
  • Does not unlock or bypass DRM / Kindle DRM
  • Does not claim Bindlore stores or trains on user book content on the core path
  • Does not claim affiliation with Anthropic, OpenAI, Google, or Chrome beyond being a Chrome Web Store extension that works with those ecosystems
  • Does not claim conversion guarantees agent quality, accuracy, or performance
  • Ownership alone is not blanket permission — press copy uses right-to-use / permission language

Quotable lines (approved phrasing)

  1. “Bindlore packages DRM-free books into SKILL.md and reference files for agent workflows. Parsing and skill-building stay in the browser.”
  2. “Core conversion processes book content on your device without sending it to Bindlore servers. Optional AI extras send requested content directly from your browser to your chosen provider using your own API key.”
  3. “DRM-locked files are refused on purpose.”
  4. Founder (Deimira Baidoo): “I own a lot of books. The problem isn’t buying them — it’s finding the useful part when I need it, and getting that into the tools I work with every day.”
  5. Founder (Deimira Baidoo): “I wanted conversion that stays on my machine — handing paid books to a vendor cloud wasn’t acceptable.”
