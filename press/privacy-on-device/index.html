FOR IMMEDIATE RELEASE

Bindlore keeps book content on the user’s device for core convert — no Bindlore cloud on that path

Calgary, Alberta — September 17, 2026

Bindlore, a free Chrome extension built by Deimira Baidoo, runs core convert in the browser on the user’s machine: parsing, OCR, and skill-building stay local. No book content touches a Bindlore server on the core convert path.

The extension converts books and documents the user has the right to process into agent-readable skill packages (SKILL.md plus chapter references) for Claude, Codex, and other Markdown-reading agents. Conversion structures source material for compatible agents; it does not guarantee agent quality, accuracy, or performance.

“I wanted conversion that stays on my machine — handing paid books to a vendor cloud wasn’t acceptable,” said Deimira Baidoo. Optional AI extras (summaries, glossary, Anki cards) use the user’s own OpenAI or Anthropic API key; those requests travel from the browser directly to the provider, not through a Bindlore book-content cloud. DRM-locked files are refused on purpose.

Product facts

  • Core convert: processing runs in the browser on the user’s device
  • No Bindlore cloud for book content on the core path
  • No account required for core convert
  • Optional AI extras: user’s own OpenAI or Anthropic key; browser → provider direct
  • DRM-locked files refused on purpose
  • Free core path available on the Chrome Web Store
  • Conversion does not guarantee agent quality
