How Bindlore fits local-first personal knowledge: right-to-use books become agent-readable skill files on your machine

Calgary, Alberta — September 17, 2026

Local-first and personal-knowledge workflows usually start with notes the user wrote. Bindlore, from Deimira Baidoo, extends that idea to books and documents the user has the right to process: convert DRM-free files — or photos of owned paper pages — into structured skill packages that stay on the device for the core path, then load into Claude, Codex, or custom agents that read Markdown. Conversion structures source material for compatible agents; it does not guarantee agent quality, accuracy, or performance.

Unlike cloud converters that hold a copy of a library to process it, Bindlore does not run a Bindlore server for book content on the core convert path. Parsing, OCR, and skill-building run in the browser. The export is not raw text alone: a SKILL.md file plus chapter references is structured so agents can cite sections, not just summarize a paste.

He described the gap as retrieval and tooling, not acquisition. “I own a lot of books. The problem isn’t buying them — it’s finding the useful part when I need it, and getting that into the tools I work with every day,” he said.

Optional AI extras keep Bindlore out of the middle for book storage: the user supplies their own OpenAI or Anthropic key; the request travels browser to provider. DRM-locked files are refused on purpose.

Product facts

  • Local-first core path: processing runs on the user’s device
  • Right-to-use library → SKILL.md skill packages for agents
  • Batch convert supported
  • No account required for core convert; free core path
