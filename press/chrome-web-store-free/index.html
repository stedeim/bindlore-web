Bindlore on the Chrome Web Store: free core convert, no account required

Calgary, Alberta — September 17, 2026

Bindlore is live as a free Chrome extension. The core path — drop a DRM-free book or document you have the right to process, preview, export an AI skill package or Markdown/Word/Text file — does not require creating a Bindlore account.

Founder Deimira Baidoo built the listing for Chrome users who already work with Claude, Codex, or other Markdown-reading agents and want library material as structured SKILL.md packages without sending book content to a Bindlore server. Parsing and OCR run in the browser. Conversion structures source material for compatible agents; it does not guarantee agent quality. Optional AI extras (summaries, glossary, Anki cards) use the user’s own OpenAI or Anthropic key, passed directly from browser to provider.

Paid extras may come later; the company states the core convert path stays free. DRM-locked files are refused on purpose.

Product facts

  • Free core convert on Chrome Web Store
  • No account required for core convert
  • On-device processing; no Bindlore cloud for book content on core path
  • Inputs: PDF, EPUB, Word, PowerPoint, TXT, photos/scans
  • Exports: AI Skill (SKILL.md + references), Markdown, Word, Text
  • Conversion does not guarantee agent quality
