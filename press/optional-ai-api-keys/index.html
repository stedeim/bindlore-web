MEDIA BRIEF

Bindlore’s optional AI extras use the user’s own OpenAI or Anthropic key — not a Bindlore book cloud

Calgary, Alberta — September 17, 2026

Bindlore’s core job — converting books and documents the user has the right to process into on-device skill packages — does not require an API key or a Bindlore account. Optional extras such as summaries, glossary generation, and Anki cards are separate: they use the user’s own OpenAI or Anthropic API key, with requests going from the browser directly to the provider.

Founder Deimira Baidoo kept that split deliberate. Core parsing and skill-building stay local. There is no Bindlore cloud for book content on the core path. When a user opts into model-backed extras, Bindlore is not positioning itself as the host of the library; the key and the provider relationship belong to the user. Conversion structures source material for compatible agents; it does not guarantee agent quality.

The free Chrome extension still refuses DRM-locked files on purpose and exports SKILL.md packages — or Markdown, Word, and plain-text formats — for Claude, Codex, and other Markdown-reading agents.

Product facts

  • Core convert: free, on-device, no account, no API key required
  • Optional extras: summaries, glossary, Anki cards (per product FAQ)
  • User’s own OpenAI or Anthropic key; browser → provider
  • Not a Bindlore-hosted book-content cloud
  • DRM-locked files refused on purpose
  • Conversion does not guarantee agent quality
